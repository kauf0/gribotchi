# ГРИБОЧИ / グリボッチ

Виртуальный чайный гриб в винтажном корпусе. Тамагочи, в котором объект
не кричит, а отворачивается и ждёт.

```
npm install
npm run dev        # http://127.0.0.1:5173
```

## Что где

| | |
|---|---|
| `src/sim/` | симуляция: чистые функции, ничего не знают о пикселях |
| `src/sim/balance.ts` | **все числа игры**, в логике магических констант нет |
| `src/view/project.ts` | единственный шов: `GameState` → `ScreenState` |
| `src/ui/controller.ts` | что делает каждая кнопка в каждом состоянии — чистая функция |
| `src/ui/reactions.ts` | когда гриб подаёт голос сам — таблица переходов |
| `src/view/` | рендер: канвас 300×240 и DOM-корпус |
| `src/demo/timeline.ts` | семь сцен ролика — второй источник того же `ScreenState` |
| `src/audio/` | синтез голоса, партитура, служебные звуки |
| `src/content/strings.ts` | все тексты и название — ровно одно место |
| `reference/` | исходный дизайн-хендофф, только для чтения |

Ключевое: экран целиком описывается плоским `ScreenState`. Симуляция ничего
не знает о пикселях, рендерер — о времени и сохранениях. Благодаря этому
аттракт-режим — не отдельный проигрыватель, а второй источник того же типа:
ролик физически не может разойтись с игрой, потому что рисовать его больше
нечем.

## Правила игры

Один игровой день — три реальных часа.

- **ЧАЙ** — кормит. Сытость пустеет за 12 реальных часов, так что ночь можно
  проспать. Перекорм закисает средой, а не запрещается.
- **МЫТЬ** — снимает плесень ценой части питания и остановки роста.
  Не декорация: плесень копится всегда и без уборки рост встаёт на 25-й день.
- **СОС** — аварийная служба: сухой вердикт об обстановке. В тупиковых
  состояниях становится выходом — розлив у доросшего, новое поколение у мёртвого;
  строка внизу экрана каждый раз говорит, что именно произойдёт.

Гриб подаёт голос сам, но только на **переходах**: отвернулся, разозлился,
загрустил, созрел для розлива или вернулся к жизни из плохого состояния.
Обычное кормление сытого объекта проходит молча — иначе реплики стали бы фоном.
Сердечки тоже не индикатор сытости, а благодарность: обиженный их не даёт.

Плесень — она же здоровье: `mold >= 1` означает смерть. Одна причинная цепочка
голод → плесень → смерть, целиком видимая игроку точками на грибе.

Номер дня считается от **прожитого симуляцией** времени (`ageMs`), а не от
разницы настенных часов. Сытость, рост и плесень копятся шагами `advance()` —
возраст обязан копиться теми же шагами, иначе источники расходятся: после
ускорения времени или переведённых системных часов параметры остаются, а
счётчик дней падает в единицу.

**Обида** копится быстро, тает медленно и только при исправном уходе. Сытость
возвращается одним нажатием, лицо — нет. В этой асимметрии весь смысл. Объект
отворачивается примерно через 15 реальных часов забвения и живёт после этого
ещё около шести — окно, в которое игрок успевает вернуться и извиниться.

Смерть окончательна, но не обнуляет игрока: доросший до половины гриб оставляет
дочерний слой, и цикл продолжается с поколения №2. Доросший до максимума
разливается в партию — та же петля, но с наградой.

## Звук

Партитура синтезируется на лету по нотам из спецификации, а не проигрывается
файлом: 1.5-мегабайтный wav зациклился бы до отвращения за день, а из нот
бесплатно получается адаптивность — темп и регистр идут за настроением объекта,
в тревоге музыка замолкает.

**Включение звучит отдельно от игры.** Пока прибор загружается, играет заряд
высоковольтного конденсатора: щелчок тумблера, ползущий вверх вой обмотки, гул
сети на 50 Гц и треск дуги, учащающийся по мере накопления заряда. Пробой
приходится ровно на кадр, где экран оживает, — и только тогда вступает главная
тема. Вальс поверх заряда был бы кашей, поэтому до конца загрузки он молчит.

Выключается накладкой со значком динамика в правом верхнем углу корпуса —
зеркально светодиоду. Значок сразу показывает состояние: волны или крестик.
Решётка динамика делает то же самое, и клавиша `M` тоже.

**Экран запуска.** Игра не начинается сама: сперва на ЖК висит «КОРМИТЬ
ГРИБОЧИ · НАЖМИТЕ СОС», и только нажатие включает прибор — с зарядом
конденсатора и построчной загрузкой. Это не заставка ради заставки: браузеры запрещают звук
до первого взаимодействия со страницей, и без такого экрана игра открывалась бы
молча, а игрок гадал бы, сломано ли что-то. Здесь нажатие — часть сюжета, и оно
же поднимает звук. Вернувшемуся владельцу экран дополнительно сообщает день и
поколение.

## PWA

`npm run icons` перерисовывает иконки из тех же токенов, что и корпус.
Service worker кеширует всё запрошенное и отдаёт игру без сети. Имя кеша
содержит версию из `package.json`: каждая сборка получает свой, старые
удаляются при активации — иначе игрок беты застревал бы на прежней версии.

**Не сделано:** уведомления «объект голоден». Чистый веб их толком не даёт —
локальные работают только при открытой вкладке, настоящие пуши требуют либо
Periodic Background Sync (только Chrome/Android), либо сервера. Реальный
ответ — обёртка Capacitor с нативными локальными уведомлениями.

## Проверка

```
npm run boot-sound                        # звук включения: /tmp/gribochi-boot.wav
npm test                                  # 161 юнит-тест: симуляция, вид, кнопки, реплики, звук
npm run e2e                               # живой прогон в браузере через CDP
npm run shot -- --all                     # опорные кадры в /tmp/gribochi-shots
npm run score away 8                      # послушать музыку: /tmp/gribochi-score.wav
```

Состояние сидируется параметрами URL (см. `src/debug/params.ts`) — это
headless-близнец отладочной панели, которая в dev-режиме висит слева:

```
?manual&mood=away&mold=.8      подменяет картинку
?sim.dead&sim.growth=.7        правит саму симуляцию
?open=report                   открывает сводку
?attract=20                    включает ролик с 20-й секунды
```

Панель работает в двух режимах, и они разведены жёстко. **Ручной**: любой
ползунок, флажок или поле подменяют картинку целиком — для сверки рендера
с кадрами референса. **Живой**: панель показывает настоящее состояние объекта,
включая обиду, которой нет в `ScreenState`, и следует за симуляцией. Кнопки
×60 и ×600 сами выключают ручной режим — иначе ускорение крутит симуляцию
за подменённой картинкой, и кажется, что время стоит.

`npm run e2e` гоняет живой браузер через CDP: нажимает кнопки, читает
сохранение, перезагружает вкладку и проверяет запуск без сети. Офлайн-проверка
работает только против собранной версии (`npm run build && npm run preview`),
на dev-сервере она честно пропускается.

## Публикация на itch.io

```
./scripts/get-butler.sh          # butler в .tools/, не в систему
npm run itch:assets              # обложка и скриншоты в itch/
npm run publish:itch -- --dry    # всё, кроме отправки
npm run publish:itch             # типы → тесты → сборка → заливка
```

Ключ и адрес игры лежат в `.env` (он в `.gitignore`). Страницу на itch нужно
завести руками — API умеет только заливать файлы; точные настройки полей
в `itch/description.md`. Канал `html5`: по этому слову itch понимает, что игру
надо запускать в браузере.

Публикация прерывается на первой же ошибке типов или теста: бета — это то, что
игроки увидят вместо игры.

## Шрифты

`npm run fonts` пересобирает `public/fonts/` из Google Fonts. Катакана
сабсетится до пяти нужных знаков — 1.2 КБ вместо мегабайтов CJK.
Handjet, PT Sans Narrow, DotGothic16 — всё под OFL.
