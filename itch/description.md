## Настройки страницы

Создаётся вручную на `itch.io/game/new` — API страницы заводить не умеет,
только заливать в существующие.

| Поле | Значение |
|---|---|
| Title | ГРИБОЧИ |
| Short description | Виртуальный чайный гриб в винтажном корпусе. Он тоже вас не забудет. |
| Classification | Game |
| Kind of project | HTML |
| Release status | In development |
| Visibility | **Restricted** — доступ по ссылке |
| Embed | Width 560, Height 780 |
| | ✓ Click to launch, ✓ Fullscreen button, ✓ Mobile friendly |
| Genre | Simulation |
| Tags | tamagotchi, pixel-art, russian, retro, virtual-pet |
| Language | Russian |

Размер встраивания не произвольный: при 560×780 множитель масштаба выходит
ровно единица, прибор 480×646 встаёт в кадр целиком, и пиксельная сетка ЖК
не рябит. На меньшем прибор обрежется, на большем — останется того же размера
с полями, потому что следующий целый шаг требует высоты от 1292 px.

Адрес страницы лежит в `package.json → itch.target` в виде «логин/игра» —
это не секрет, а свойство проекта:

```json
"itch": { "target": "deemkeen/gribotchi", "channel": "html5" }
```

Страница: https://deemkeen.itch.io/gribotchi

Релиз — `npm version patch && git push --follow-tags`, дальше GitHub Actions.

## Текст описания

Лежит готовым HTML в **`itch/page.html`** — вставлять оттуда.

itch не разбирает markdown: звёздочки и решётки он покажет как есть, а каждый
перенос строки превратит в отдельный абзац. Поэтому единственный источник
текста страницы — html-файл, чтобы не было соблазна скопировать markdown.

Разрешённые там теги: `h2`, `h3`, `p`, `strong`, `em`, `ul`, `li`, `hr`.

## Это бета — что честно сказать сразу

- Интерфейс **только на русском**.
- **Уведомлений нет.** «Объект голоден» приходит, только пока вкладка открыта:
  чистый веб фоновых напоминаний толком не даёт. Настоящее решение — обёртка
  в приложение, и оно ещё впереди.
- В **полноэкранном режиме на экране 1080p** прибор остаётся того же размера
  и не растягивается. Пиксельная сетка требует целого множителя, а следующий
  шаг просит высоту от 1292 px, так что вырастает он только на 1440p и выше.
- Полный цикл жизни занимает **около трёх с половиной реальных суток**. Если
  хотите увидеть смерть и смену поколения — гриб надо честно забыть примерно
  на сутки.

Номер версии показывает **СОС** — первая строка после вердикта. Он пригодится
в отзыве об ошибке.
