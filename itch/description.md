# Материалы страницы itch.io

Собрано скриптом `npm run itch:assets`. Пересобрать можно в любой момент —
кадры снимаются из самой игры, поэтому не устаревают при редизайне.

### Обложка

| Файл | Куда | Замечание |
|---|---|---|
| `cover-animated.gif` 630×500, 60 КБ | **Cover image** | Витрина крутит GIF прямо в ленте — живой прибор там читается несравнимо лучше застывшего. Берите его, а не png. |
| `cover.png` 630×500 | запасная обложка | Финальная плашка ролика. Если анимация покажется навязчивой. |

### Скриншоты

Порядок важен: первый кадр показывается крупнее прочих.

| Файл | Что на нём |
|---|---|
| `wide-1-komnata.png` 960×540 | Прибор на столе — общий план, ставить первым |
| `screen-3-obida.png` 560×780 | Обида: «ОН ВСЁ ПОМНИТ» — главный кадр игры |
| `screen-2-kormlenie.png` 560×780 | Кормление: сахар и сердечки |
| `screen-4-svodka.png` 560×780 | Сводка аварийной службы |
| `screen-1-zapusk.png` 560×780 | Экран запуска |
| `wide-2-final.png` 960×540 | Финальная плашка |

Вертикальные кадры сняты ровно в том размере, в каком игра встанет на странице,
широкие — для ленты, где горизонтальные читаются лучше.

### Оформление страницы

`Edit theme` на странице игры. Цвета взяты из палитры самой игры
(`src/content/tokens.ts`), поэтому страница и прибор смотрятся одним предметом.

| Поле | Значение | Откуда |
|---|---|---|
| Background | `#16170f` | дальняя стена комнаты |
| Text | `#d9c9a3` | светлая краска на корпусе |
| Link | `#e05a3a` | светодиод |
| Button background | `#8e3a2a` | кнопка СОС |
| Button text | `#f0e4cd` | надпись на ней |
| Border | `#2a2b21` | стена в полутени |

**Фон:** ровный `#16170f` — прибор на нём стоит спокойно.

Если хочется фактуры, в `tile-cloth.png` лежит бесшовная клеёнка со стола
(92×92, тот же расчёт, что и в комнате игры) — ставится в `Background image`
с повторением по обеим осям. Предупреждение: во всю страницу клетка получается
громкой и спорит со скриншотами. Лучше ровный цвет.

**Шрифты страницы** менять не нужно: гарнитуры игры (Handjet, PT Sans Narrow,
DotGothic16) живут внутри прибора, и повторять их в вёрстке itch — перебор.

## Настройки страницы

Создаётся вручную на `itch.io/game/new` — API страницы заводить не умеет,
только заливать в существующие.

| Поле | Значение |
|---|---|
| Title | ГРИБОЧИ |
| Short description | Виртуальный чайный гриб в винтажном корпусе. Он тоже вас не забудет. |
| Classification | Game |
| Kind of project | HTML |
| Release status | In development |
| Visibility | **Restricted** — доступ по ссылке |
| Embed | Width 560, Height 780 |
| | ✓ Click to launch, ✓ Fullscreen button, ✓ Mobile friendly |
| Genre | Simulation |
| Tags | tamagotchi, pixel-art, russian, retro, virtual-pet |
| Language | Russian |

Размер встраивания не произвольный: при 560×780 множитель масштаба выходит
ровно единица, прибор 480×646 встаёт в кадр целиком, и пиксельная сетка ЖК
не рябит. На меньшем прибор обрежется, на большем — останется того же размера
с полями, потому что следующий целый шаг требует высоты от 1292 px.

Адрес страницы лежит в `package.json → itch.target` в виде «логин/игра» —
это не секрет, а свойство проекта:

```json
"itch": { "target": "deemkeen/gribotchi", "channel": "html5" }
```

Страница: https://deemkeen.itch.io/gribotchi

Релиз — `npm version patch && git push --follow-tags`, дальше GitHub Actions.

## Текст описания

Лежит готовым HTML в **`itch/page.html`** — вставлять оттуда.

itch не разбирает markdown: звёздочки и решётки он покажет как есть, а каждый
перенос строки превратит в отдельный абзац. Поэтому единственный источник
текста страницы — html-файл, чтобы не было соблазна скопировать markdown.

Разрешённые там теги: `h2`, `h3`, `p`, `strong`, `em`, `ul`, `li`, `hr`.

## Это бета — что честно сказать сразу

- Интерфейс **только на русском**.
- **Уведомлений нет.** «Объект голоден» приходит, только пока вкладка открыта:
  чистый веб фоновых напоминаний толком не даёт. Настоящее решение — обёртка
  в приложение, и оно ещё впереди.
- В **полноэкранном режиме на экране 1080p** прибор остаётся того же размера
  и не растягивается. Пиксельная сетка требует целого множителя, а следующий
  шаг просит высоту от 1292 px, так что вырастает он только на 1440p и выше.
- Полный цикл жизни занимает **около трёх с половиной реальных суток**. Если
  хотите увидеть смерть и смену поколения — гриб надо честно забыть примерно
  на сутки.

Номер версии показывает **СОС** — первая строка после вердикта. Он пригодится
в отзыве об ошибке.
